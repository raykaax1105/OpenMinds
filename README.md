# OpenMinds 🌿
### Diferentes formas de viver, um mundo para todos.

## Sobre o projeto

O **OpenMinds** é um site desenvolvido com o objetivo de compartilhar informações sobre acessibilidade e inclusão na vida cotidiana.

A proposta é conscientizar os visitantes sobre as diferentes necessidades das pessoas e mostrar como pequenas atitudes e adaptações podem contribuir para uma sociedade mais acessível e inclusiva.

## Objetivos

- Informar sobre os diferentes tipos de acessibilidade.
- Incentivar o respeito às diferenças.
- Apresentar exemplos de inclusão no cotidiano.
- Promover a conscientização sobre a importância da acessibilidade.

## Páginas do site

O site é composto por cinco páginas:

1. **Início:** apresentação do projeto e introdução à acessibilidade.
2. **Acessibilidade Visual:** informações sobre acessibilidade para pessoas com deficiência visual.
3. **Acessibilidade Auditiva:** informações sobre acessibilidade para pessoas com deficiência auditiva.
4. **Acessibilidade Motora:** informações sobre mobilidade e acessibilidade física.
5. **Inclusão:** exemplos de atitudes que contribuem para uma sociedade mais inclusiva.

## Recursos de acessibilidade

O projeto conta com recursos para facilitar a navegação e a leitura:

- Aumento e diminuição do tamanho da fonte.
- Opção de alto contraste.
- Navegação por teclado.
- Opção para reduzir animações.
- Textos alternativos para imagens.
- Organização semântica do conteúdo.
- Layout adaptável a diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5
